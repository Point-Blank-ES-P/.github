## 🚀 Why Choose Point Blank ESP?

Compact maps mean constant contact. The overlay keeps boxes, health, and distance readable without filling the screen, and bombsite markers add the objective context that plain ESP tools miss.

Each element toggles independently, so a minimal layout for ranked and a fuller one for review can coexist.

## 🧩 Quick Start

1. Launch **Point Blank** and open the ESP panel.
2. Enable boxes, skeletons, health, and loadout info.
3. Set team colors and range filters.
4. Turn on bombsite markers.
5. Save the layout as a profile.
